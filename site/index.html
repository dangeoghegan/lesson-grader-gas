Connect your Apps Script deployment

This page is a plain static file hosted on GitHub. It holds no code about your school, your Drive or your Gemini key — it only remembers where the Lesson Grader web app lives. Paste the deployment address once and it is saved in this browser.

In Apps Script: Deploy → Manage deployments → ✎ → Web app, then copy the Web app URL that ends in /exec.

Permissions stay in Apps Script. The embedded app is your real deployment: it runs as the teacher who is signed in, checks LESSON_GRADER_ALLOWED_EMAILS in Script Properties, and keeps the Gemini key server-side. Nothing about access control lives in this page.
