Student data stays protected

Teacher access

A school-restricted Apps Script deployment must run as the accessing user. The owner sets LESSON_GRADER_ALLOWED_EMAILS in Script Properties. Missing access denies all grading APIs.

The connection test sends only a small “Ping” request — no student submissions, names or rubric files. When you run AI on a student, files are sent to Gemini to propose a draft only.

Read docs/IMPLEMENTATION.md for deployment, backup and key setup steps. Never deploy the web app as “Anyone · run as me”.

⌁
Access needed

A teacher account is required.

Sign in with your approved school account. The owner must configure LESSON_GRADER_ALLOWED_EMAILS in the Apps Script project settings and deploy the app as the accessing user. No workbook or student data has been loaded.
